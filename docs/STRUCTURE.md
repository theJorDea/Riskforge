## Общие конвенции (важно, используются везде)

| Конвенция | Значение |
|---|---|
| `alpha` | уровень доверия, напр. `0.99`. Ожидаемая частота пробитий = `1 - alpha` |
| Знак VaR/ES | **положительные числа** (величина потерь). Всегда `ES >= VaR` |
| Доходности | дневные лог-доходности `r_t = ln(P_t / P_{t-1})` |
| Чистые функции | одинаковый вход → одинаковый выход; Monte Carlo принимает явный `seed` |
| Тесты | математика проверяется на синтетике с известным точным ответом |

## `riskforge/data.py` — данные

**Задача:** скачать Adj Close через `yfinance`, закэшировать в `data/*.parquet`
(чтобы ноутбуки работали офлайн и были воспроизводимы), посчитать лог-доходности.

**Реализовать:**
- `load_prices(tickers, start, end, use_cache)` — ключ кэша из тикеров+дат;
  обработать случай одного тикера (yfinance возвращает Series); `dropna(how="any")`.
- `log_returns(prices)` — уже реализована: `np.log(prices).diff().dropna()`.

**Почему лог-доходности:** аддитивны по времени, для дневных движений ≈ простым доходностям.

## `riskforge/portfolio.py` — портфель

- `portfolio_returns(returns, weights)` — `r_p,t = w' r_t`; по умолчанию равные веса `1/N`;
  валидация: длина весов = N, сумма ≈ 1.
- `sample_covariance(returns)` — выборочная ковариация.

**Допущение (зафиксировать в README):** лог-доходности не агрегируются линейно по активам,
но на дневном горизонте ошибка пренебрежимо мала.

## `riskforge/var/` — Value-at-Risk и Expected Shortfall

### `historical.py`
Эмпирический квантиль прошлых доходностей. Без распределительных предположений.

- `VaR_α = -Quantile_{1-α}(r)`
- `ES_α = -E[r | r ≤ Quantile_{1-α}(r)]`

### `parametric.py`
- Normal: `VaR_α = -(μ + σ·z_{1-α})`, где `z = Φ⁻¹`
- Student-t: подобрать `ν` через MLE (`scipy.stats.t.fit`), квантиль t-распределения.

**Зачем Student-t:** у дневных доходностей жирные хвосты (эксцесс >> 3),
нормальная модель систематически занижает хвостовой риск — показать в ноутбуке 02.

### `monte_carlo.py`
1. Оценить `μ (N,)` и `Σ (N,N)` по истории.
2. `n_sims` сценариев `r ~ N(μ, Σ)` через `np.random.default_rng(seed).multivariate_normal`.
3. P&L сценария: `p = r @ w`; `VaR_α = -quantile(p, 1-α)`.

Расширение (опционально): multivariate Student-t для совместных жирных хвостов.

## `riskforge/volatility/` — модели волатильности

### `ewma.py` (RiskMetrics, JPMorgan 1996)
`σ_t² = λ·σ_{t-1}² + (1-λ)·r_{t-1}²`, дневная классика `λ = 0.94`.
Это IGARCH без mean reversion (`ω=0, α=1-λ, β=λ`).
**Писать руками на NumPy** — смысл модуля в демонстрации понимания рекурсии.
Инициализация `σ_0²` — выборочная дисперсия первых ~30 точек (задокументировать выбор).

### `garch.py` — GARCH(1,1) со своей MLE
- Модель: `σ_t² = ω + α·r_{t-1}² + β·σ_{t-1}²`, ограничения `ω>0, α,β≥0, α+β<1`.
- Лог-правдоподобие (гауссово): `L = -0.5·Σ[ln(2π) + ln(σ_t²) + r_t²/σ_t²]`.
- Оптимизация: `scipy.optimize.minimize` (L-BFGS-B, bounds), внутри objective
  возвращать `+inf` при `α+β ≥ 1`.
- Прогноз: `σ²_{t+h} = σ²_uncond + (α+β)^h·(σ_t² - σ²_uncond)`.
- **Кросс-чек с пакетом `arch` в тестах** — главный пруф корректности.

## `riskforge/backtest/` — проверка моделей (киллер-фича проекта)

### `kupiec.py` — POF-тест (Kupiec, 1995)
Проверяет ЧИСЛО пробитий: `LR_pof ~ χ²(1)` при H0 "частота пробитий = 1-α".
Считать в лог-пространстве (иначе underflow при больших T);
обработать края `x=0` и `x=T` (члены `0·ln(0) → 0`).

### `christoffersen.py` — тест независимости (1998)
Проверяет КЛАСТЕРИЗАЦИЮ пробитий (марковская цепь 1-го порядка, `π_01 vs π_11`).
`LR_ind ~ χ²(1)`; комбинированный `LR_cc = LR_pof + LR_ind ~ χ²(2)`.
Хорошая модель: пробития независимы; кластеры = модель медленно реагирует на смену режима.

### `runner.py` — rolling-window бэктест
Для каждого дня t: окно `[t-window, t)` → оценка VaR → пробитие если `r_t < -VaR_t`.
Окно по умолчанию 250 (торговый год). Сначала простой читаемый цикл, оптимизация потом.
Выход — DataFrame `(return, var, breach)` — идёт в тесты и графики.

- На `N(0,σ²)`: все три VaR сходятся к аналитике `-σ·z_{1-α}`.
- Своя GARCH MLE восстанавливает параметры симулированного процесса и совпадает с `arch`.
- Kupiec не отвергает корректную модель и жёстко отвергает мискалиброванную; edge cases.
- Тесты помечены `@pytest.mark.skip("TODO: ...")` — **снимать skip по мере реализации модулей** (smoke-тест импорта держит CI зелёным с первого дня).
